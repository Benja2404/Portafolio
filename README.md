# Portafolio digital

Sitio web estático construido con Astro para presentar mi marca personal como desarrollador web.

## Propósito

Mostrar una identidad visual clara, habilidades técnicas y blandas, proyectos reales y medios de contacto en una sola página responsiva.

## A quién representa

Este sitio me representa a mi Benjamin Contreras, como un desarrollador con soluciones reales y despliegue constante.

## Enfoque de marca personal

- Estilo minimalista con acentos modernos.
- Paleta sobria y profesional.
- Contenido enfocado en presentación, habilidades, portafolio y contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Astro

## Cómo visualizar el sitio

1. Instalar dependencias:
   - `npm install`
2. Ejecutar el proyecto en desarrollo:
   - `npm run dev`
3. Abrir la dirección que muestre Astro en el navegador.

También puedes compilarlo con:

- `npm run build`
